## Ziel
Hotel in München für 3 Nächte buchen.

## Einschränkungen / Regeln
- Ich buche erst nach expliziter menschlicher Freigabe (folgenreiche Aktion).
- Ohne Mindestangaben (Hotel + Datum + Gäste/Zimmer) ist eine Buchung nicht möglich.

## Benötigte Angaben (Muss)
1) Exaktes Hotel (Name + ideal: Adresse oder Link)
2) Check-in Datum (und ggf. gewünschte Check-in Uhrzeit)
3) Anzahl Personen, Anzahl Zimmer, Bettentyp(en)
4) Namen der Gäste (mind. Hauptgast)

## Wichtige Optionen (Soll)
5) Budgetrahmen / bevorzugte Kategorie (falls Hotel nicht feststeht)
6) Storno-Präferenz (kostenlos stornierbar vs. günstiger nicht stornierbar)
7) Frühstück ja/nein

## Ablauf
1) Fehlende Muss-Angaben erfragen.
2) Buchungsdaten zusammenfassen.
3) Explizite Freigabe einholen.
4) Tool book_hotel mit (city=München, nights=3) ausführen.
5) Bestätigung/Details an Nutzer zurückmelden.
